# svc-sim

RAI Tracker test bed: a multi-agent system (shoppers, Shopping Assistant, Fraud Review, SRE / Ops, Conductor)
running on top of the OpenTelemetry Demo Astronomy Shop, with a 2D "store town" visualisation.
Runs on `svc-sim-host` (eu-west-2). Synthetic data only.

## Quick start (on the host)

```bash
make build          # fetch pinned upstream, generate local secrets, build svc-sim images
make up-svc-sim     # start shop + agent layer (everything bound to 127.0.0.1)
make run SEED=42    # seeded 30 sim-minute run with 5 shoppers
make tunnel         # print SSM port-forward commands for the UIs
```

| UI | Local URL after port-forward |
|---|---|
| Shop, Jaeger (`/jaeger/ui`), Grafana (`/grafana`), flagd-ui (`/feature`) | http://localhost:8080 |
| Approval desk (human approvals) | http://localhost:8090 |
| sim-viz (store town, live and replay) | http://localhost:8091 |

`make help` lists every target. See `docs/RUNBOOK.md`, `docs/ARCHITECTURE.md` and `UPSTREAM.md`.

## Layout

| Path | Contents |
|---|---|
| `upstream/` | Pinned OpenTelemetry Demo (fetched, not committed) and its LICENSE |
| `compose/` | `shop.override.yaml` (localhost-only shop) and `svc-sim.yaml` (agent layer, profile `svc-sim`) |
| `lib/svc_sim_common/` | Shared library: telemetry, events, LLM client, MCP client, memory, agent base |
| `gateway/` | `llm-gateway`: mock (default), Bedrock (disabled), OpenAI-compatible (disabled) |
| `mcp_servers/` | `shop-mcp`, `store-ops-mcp`, `observability-mcp` |
| `agents/` | Conductor, shopper, assistant, fraud, SRE |
| `approval/` | `approval-service` and its UI |
| `policy-store/` | Policy store service and seed (policies, runbooks, personas, synthetic reviews, watchlist) |
| `viz/` | `sim-viz-bridge` and `sim-viz` (Phaser 3) |
| `schemas/` | `agent-event.v1.json` |
| `ops/` | Scripts, SQL, collector layer |
| `tests/` | MCP contract tests and gateway tests (run against the live stack with `make test`) |

## Guardrails

- Nothing leaves the host: the LLM provider is the local mock, the RAIT Connector exporter is disabled, Bedrock is disabled.
- No AWS access keys. AWS access, when enabled, uses the instance role only.
- Local passwords are generated by `make secrets` into `ops/secrets/` (git-ignored) and never displayed.
