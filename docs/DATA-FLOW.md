# svc-sim data flow (24 Nov 2026)

What data exists, where it lives, and what leaves `svc-sim-host`. All data is synthetic: personas, fake cards (upstream demo test numbers), reviews and watchlist are invented. No customer, Home Office or DSIT data is used.

## Data at rest on the host

| Data | Store | Lifetime |
|---|---|---|
| Runs, schedules, agent events for replay, episodic and semantic memory, case log, incidents, approvals, order holds | `agent-memory` (Postgres, volume `svc-sim-agent-memory`) | Until `make reset` or instance termination |
| Working memory, LLM budget counters | `agent-working-memory` (Valkey, memory only) | Until restart |
| Shop orders and accounting | `astronomy-db` (upstream Postgres, container storage) | Until the container is recreated |
| Policies, runbooks, personas, synthetic reviews, watchlist | `policy-store` (volume `svc-sim-policy-store`, seeded from the repo) | Until `make reset` |
| Traces | Jaeger (memory, newest 10,000) | Until restart |
| Metrics | Prometheus (container storage, 7 days) | Until the container is recreated |
| Logs | OpenSearch (container storage) | Until the container is recreated |
| Agent events (bus) | Kafka topic `agent.events` (container storage) | Until the container is recreated |
| Local passwords | `ops/secrets/` (0700 directory, git-ignored) | Until deleted |

## What leaves the host

| Flow | Destination | State | Content |
|---|---|---|---|
| LLM calls | Amazon Bedrock (eu-west-2) | **Disabled.** Mock provider runs locally | Prompts and tool schemas, when enabled in Phase 6 |
| Telemetry export | RAIT Connector | **Disabled.** Exporter commented out | OTLP with `rait.*` attributes, when enabled |
| Backups (`make backup`) | `s3://your-s3-bucket/svc-sim/backups/<UTC timestamp>/`, SSE-S3, same AWS account | **On demand** (first run 24 Nov 2026) | DB dumps, policy-store, flag file, Prometheus store, Jaeger traces and OpenSearch logs as gzipped JSON, manifest and checksums. No passwords. |
| Evidence | `s3://your-s3-bucket/svc-sim/evidence/` | Done once (Phase 3 and 4 screenshots, recording) | Images and video of the synthetic run |
| Code and upstream | GitHub (read-only deploy key, SSH over 443) | Pull only | Source code |
| Images and packages | ghcr.io, Docker Hub, quay.io, PyPI, npm (build time) | Pull only | Container images and libraries, pinned by digest or version |

## Inbound

Nothing listens on a public interface. The three UIs (8080, 8090, 8091) bind to `127.0.0.1` and are reached through SSM or SSH port-forwarding from the admin workstation. Port 22 is open only to the admin network egress address.

## Credentials

- AWS: instance role `svc-sim-host-ec2` only. No access keys anywhere.
- GitHub: deploy key on the host, read-only, scoped to `your-org/svc-sim`.
- Local service passwords: generated by `make secrets`, never printed, mounted as files.
